# `@archipielago/nestjs`

NestJS host adapter: `mountArchipielagoAssets` for production static client
files or development Vite middleware. Product HTML stays on the host
(Handlebars in the Nest example).

Documentation home: [docs/archipielago/README.md](../../docs/archipielago/README.md). Nest mapping: [guide/nestjs.md](../../docs/archipielago/guide/nestjs.md). Runnable example: [examples/nestjs](../../examples/nestjs/README.md).
